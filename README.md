# 👗 Tamid – Clothing E-Commerce Website

![Bootstrap Logo](https://getbootstrap.com/docs/5.3/assets/brand/bootstrap-logo-shadow.png)

## 📖 Overview
**Tamid** is a stylish and responsive clothing e-commerce website built using **HTML**, **CSS**, and **Bootstrap**.  
It showcases my skills in **web design**, **UI/UX aesthetics**, and **smooth navigation**.

The website covers the complete online shopping experience:
1. **User Login**
2. **Product Browsing**
3. **Category Filtering**
4. **Checkout with Buyer Details**

---

## 🎯 Key Objectives
- Demonstrate **web design** and **frontend development** skills.
- Provide **intuitive navigation** for an online store.
- Display **gender-based** and **season-based** product categories.
- Offer a complete shopping flow from login to checkout.

---

## 🛠 Features
- ✅ **Responsive design** with Bootstrap for all screen sizes.
- ✅ **Gender categories** (Men, Women, Kids).
- ✅ **Seasonal categories** (Summer, Winter, etc.).
- ✅ **Aesthetic product cards** with appealing layouts.
- ✅ **Login and authentication form** (frontend only).
- ✅ **Checkout form** to enter buyer details.
- ✅ **Easy navigation** with navbar & footer.

---

## 🖥️ Technologies Used
- **HTML5** – Structure & markup.
- **CSS3** – Styling & custom designs.
- **Bootstrap** – Responsive layout & UI components.
